# Bangladesh coronary pathway demo — screen mock-ups

Clickable mock-ups for the dummy demo of the NCD corner → cath-lab hub pathway, with the coordination layer between them.

- `index.html` — landing page with links to both systems
- `NCD_corner_screens.html` — five corner screens (due-list, visit, patient journey, referral and Find-a-service, inbox)
- `Cath-lab_hub_screens.html` — four hub screens (referrals, discharge and plan, hub review, service register)

Each file is self-contained: open it in a browser, or serve it from GitHub Pages. Screens re-date themselves to the current week; `?site=sylhet` switches the facility names from Bogura to Sylhet; `#visit`, `#review` and the other menu slugs open a given screen.

Static mock-ups: buttons do not act, nothing is saved or sent. Public facilities are real; the private clinic is invented, and all patients, dates and appointment slots are illustrative.
